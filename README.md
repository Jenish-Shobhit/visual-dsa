# Visual DSA

A visual guide to data structures and algorithms that starts with what code does and earns each idea from the one before it. It is for first-time programmers and anyone who wants to see a process before memorizing its name.

## Run

Open `index.html` in a browser. No installation, server, framework, or build step is needed.

## Design rules

Strict 12-column grid; flush-left asymmetric layouts and generous whitespace.
Helvetica Neue / Helvetica / Arial; black type on white; one red accent `#e2001a`; light mode only.
Type leads. No external CSS or JavaScript. Shared `css/atlas.css` and `js/figure.js` support the chapter figures.
