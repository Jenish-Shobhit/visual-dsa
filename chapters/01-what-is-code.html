What is
code?

Code is a set of instructions. The interesting part is what changes after each one.

About 5 minutes · Use ← → in the figure

Imagine a small box labeled total. Put the number 2 inside it. Then take out that number, add 3, and put the answer back. Finally, show what is in the box.

total = 2
total = total + 3
show(total)

Those three lines are a program. It starts with no value for total. The first line gives it one. The second uses its current value to make a new one. The third produces visible output: 5.

Order matters. If you try to show total before giving it a value, there is nothing useful to show. If you add 3 before the final line, the output changes. A computer follows the given steps; it does not guess the result you meant.

Read one line at a time.

The equals sign here means “store the value on the right under the name on the left.” It is an action, not a claim that two expressions are permanently equal. In total = total + 3, the right-hand total means the value already stored; the left-hand total is where the new result goes.
