Arrays and
strings.

When one name holds a sequence, a position tells you which value to read.

About 7 minutes · Use ← → in the figure

Three scores could live under three separate names. But if you want to visit every score, one ordered collection is easier:

scores = [4, 7, 2]
show(scores[1])

This shows 7. The square brackets after scores choose a position, called an index. Counting starts at zero: scores[0] is 4, scores[1] is 7, and scores[2] is 2. There is no scores[3] in this three-item array.

The order is part of the data. If you replace scores[1] with 9, the array becomes [4, 9, 2]. The other positions keep their values. This gives a program a precise way to change one item without naming every item separately.

Visit each position.

To total the scores, start a variable at zero, then visit indices 0, 1, and 2. Each visit adds one value to the running total. The figure traces these reads. Notice how the index changes separately from the total.

A string is also an ordered sequence: "CAT" has "C" at index 0, "A" at index 1, and "T" at index 2. The same position idea helps you inspect text one character at a time. Some programming languages let you change array entries but treat strings as unchangeable; the reading idea still carries over.
