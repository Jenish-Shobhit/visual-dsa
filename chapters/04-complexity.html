Chapter 04 · After arrays

Complexity.

When the input grows, count the work that grows with it.

About 7 minutes · Use ← → in the figure

Suppose you have a row of names and need to find one name. With 4 names, you might check 4. With 40 names, you might check 40. The work grows with the row.

for each name in names:
    check(name)

If the name is last, the loop makes one check per item. For n items, that is n checks. Now imagine comparing every name with every name:

for each first in names:
    for each second in names:
        compare(first, second)

Each of the n outer visits starts n inner visits, so there are n × n comparisons. At 10 items that is 100; at 100 items it is 10,000. Step the figure to see the gap open.

Describe growth, not seconds.

One computer may run a loop faster than another. Growth describes the shape of the work as input size changes. We write O(n) for an upper bound proportional to n, and O(n²) for an upper bound proportional to n². A fixed number of steps is O(1). Big O is an upper bound; Θ names a tight bound when both upper and lower growth match.

When counting, keep the part that grows fastest. A loop doing 3n + 8 simple steps is O(n); constants still affect real runs, but they do not change that growth category. A nested loop over all pairs is O(n²). An algorithm may also use extra memory, so ask the same growth question about its working space.

Be clear about the case.

A search may find its target immediately or only after checking every item. State whether you mean best, worst, or average behavior. Input order can matter as much as input length. The sorting chapter uses these counts to compare different plans for the same task.

Practice

  1. Trace a scan of [8, 3, 5, 1, 9] for the target 9. How many values does it read in the worst case?
  2. A procedure does 2n + 5 steps; another does n × n. Count each at n = 10 and n = 100. Which grows faster?
  3. For every item in an array, a program checks every item, including itself. How many comparisons does it make for n items, and what is its growth class?
