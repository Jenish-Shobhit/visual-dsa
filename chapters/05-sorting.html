Lesson 08 · After complexity

Sorting.

Six ways to put the same values in order. The important question is what each method knows after every move.

Explore at your pace · 12 minutes

Imagine numbered cards in a row: [8, 3, 5, 3]. Sorting means arranging them so each value is no greater than the next. You can solve that by trading neighbors, selecting a minimum, inserting into an ordered prefix, merging ordered runs, partitioning around a pivot, or maintaining a heap.

Each method eventually makes the same ordered row, but its reason for making the next move differs. That reason is its invariant: something that stays true while the rest of the work continues. In the lab, stop before a move and predict it from the invariant.

Time and space describe the sorting method, not the frame history kept by this teaching tool. One swap counts as two array writes.

Three things to notice.

1. Sorted so far is different from final. Insertion sort maintains a sorted left prefix, and merge sort produces sorted runs. Later values can still move those entries. Green appears only when a position is provably final.

2. Equal values have a history. The small number below a bar is its original position. A stable sort keeps equal values in that original order. Try 5, 3, 5, 2 with merge sort, then selection sort, and watch the two fives.

3. Input shape changes work. Reverse the row, then choose quick sort. This version uses the first value as pivot; one side can contain nearly every other value. Try bubble sort on a sorted row: its no-swap pass stops early. Compare the counters, not just the animation speed.

Which method would you choose?

Insertion sort is simple and good for small or nearly sorted rows. Merge sort gives reliable n log n time and preserves equal-value order, while using another array. Heap sort also gives n log n worst-case time with constant working space, but is not stable. Quick sort often performs well, yet this pivot choice has a quadratic worst case. The right choice depends on the input, memory, and whether equal values must keep their order.
