What to look for.

Bubble sort swaps neighboring values that are out of order. Selection sort looks for the smallest remaining value and moves it forward. Insertion sort grows an ordered section one value at a time.

Merge sort divides the work into parts and combines them. Quick sort places a chosen pivot, then works on either side. Heap sort uses a heap to repeatedly move the largest remaining value to the end. Try the same array size with each method and compare how much motion you see.

The time figures describe how work grows as the input grows. They are useful for comparison; a short animation alone cannot prove them.
