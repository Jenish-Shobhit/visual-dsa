THE ALGORITHMPseudocode
  1. low = 0; high = last index
  2. while low <= high:
  3. mid = floor((low + high) / 2)
  4. if a[mid] == target: return mid
  5. if a[mid] < target: low = mid + 1
  6. else: high = mid - 1
  7. return NOT_FOUND

WHAT STAYS TRUEIf the target exists, it is still inside the remaining range.

Think first: Why would this fail if the numbers weren’t sorted?
Check your intuition

Sorted order lets a middle value speak for everything on one side. Without it, a smaller middle value tells you nothing about the values to its left. You could discard the target.
